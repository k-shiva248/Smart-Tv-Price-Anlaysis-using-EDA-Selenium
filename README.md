# Smart-Tv-Price-Anlaysis-using-EDA-Selenium
Smart TV Price Analysis project using Python, Selenium, and EDA. Performed web scraping, data cleaning, visualization, hypothesis testing, and correlation analysis to uncover pricing trends, brand performance, and customer insights. Built during training at Innomatics Research Labs.

# 📊 Smart TV Price Analysis using EDA & Web Scraping

## 📌 Project Overview

This project focuses on analyzing Smart TV prices using Exploratory Data Analysis (EDA) and Web Scraping techniques. Data was collected from e-commerce websites using Selenium and analyzed to identify pricing trends, customer preferences, and brand performance.

The project was completed as part of training at Innomatics Research Labs.

---

# 🎯 Objectives

* Collect Smart TV data using web scraping
* Perform data cleaning and preprocessing
* Analyze pricing trends and customer ratings
* Compare brands, screen sizes, and resolutions
* Generate business insights and recommendations

---

# 📂 Project Workflow

## 1️⃣ Web Scraping

* Extracted Smart TV data from e-commerce websites
* Collected:

  * Brand
  * Price
  * Rating
  * Screen Size
  * Resolution
  * Operating System

## 2️⃣ Data Cleaning

* Removed duplicate values
* Handled missing values
* Converted data types
* Cleaned price columns
* Formatted categorical data

## 3️⃣ Exploratory Data Analysis (EDA)

### 🔹 Univariate Analysis

* Price distribution
* Brand frequency
* Rating distribution

### 🔹 Bivariate Analysis

* Price vs Rating
* Price vs Screen Size
* Brand vs Average Price

### 🔹 Multivariate Analysis

* Brand, Rating, and Price relationship
* Screen Size impact on pricing

---

# 📈 Hypothesis Testing

Performed statistical testing to understand relationships between variables.

* Correlation Analysis
* Pearson Correlation
* P-value Interpretation

---

# 🔍 Key Insights

* Premium brands have higher average prices
* Larger screen sizes significantly increase prices
* Most Smart TVs fall into the mid-range category
* Higher-rated TVs generally have better pricing
* Price distribution is right-skewed due to premium TVs

---

# 💡 Business Recommendations

* Focus on mid-range Smart TVs for higher customer demand
* Improve product ratings to increase customer trust
* Offer multiple screen-size options
* Maintain competitive pricing strategies
